# Автообновление статистики YouTube

Сайт по-прежнему читает `yt-stats.json`. GitHub Actions обновляет этот файл раз в день в 06:17 UTC и позволяет запуск вручную.

1. Размести содержимое папки `index` в корне GitHub-репозитория (включая скрытую папку `.github`).
2. В GitHub открой Settings → Secrets and variables → Actions → New repository secret.
3. Назови секрет `YOUTUBE_API_KEY` и вставь действующий ключ YouTube Data API v3. Не отправляй ключ в чат и не добавляй в файлы сайта.
4. Открой Actions → Update YouTube statistics → Run workflow для первого запуска.
5. Проверь, что `yt-stats.json` обновился. Если сайт развёрнут из этого репозитория, изменения попадут на сайт после публикации.

Важно: это решение рассчитано на размещение исходников в GitHub с правом записи для Actions. При хостинге через FTP или другую систему потребуется отдельная настройка деплоя. Запланированные задания GitHub могут запускаться с задержкой.
